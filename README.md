# NTR POV Free Camera (NTR Master 第一人称与自由飞行相机)

适用于游戏《NTR Master》的 BepInEx 自由相机与第一人称 (POV) 拓展插件。

支持场景中**任意角色**（主角、女友、黄毛、女仆等）的第一人称视角切换，具备完全解耦的视角自由旋转、头部网格防遮挡（藏头）、平滑自由飞行摄像机与游戏内可视化控制菜单。

---

## ✨ 核心特性

- 🎯 **真第一人称 POV (First-Person View)**
  - 精确贴合人形角色的头部骨骼。
  - **视角独立解耦**：视线方向不再死板跟随角色头部动画晃动，支持鼠标右键全向平滑自由观察。
  - **智能头部隐藏**：进入第一人称时自动将当前角色的头部/发型进行骨骼收缩，彻底解决后脑勺与头发穿模遮挡屏幕的问题。
  - **主角模型保护**：进入主角视角时会自动唤起原本被游戏隐藏的主角模型，并绕过游戏自带的近距消隐（防半透明）。

- 🕊️ **自由飞行摄像机 (Free Fly Camera)**
  - 随时脱离角色身体，进入自由穿梭观察模式。
  - 支持 `WASD` 平移、`Q/E` 垂直升降、`Shift` 一键加速。
  - 自由飞行模式下可一键隐藏全场角色头部，方便极近距离特写拍摄。

- 🖥️ **游戏内交互菜单**
  - 按 `F10` 随时呼出可视化浮动窗口。
  - 自动扫描并列出场景内所有活体及隐藏角色，支持点击或键盘方向键快速附身。
  - 界面完全基于运行时动态绘制，不依赖易失效的静态注入。

- 🔍 **无级 FOV 缩放**
  - 在非菜单状态下，使用鼠标滚轮即可在 20° ~ 110° 之间实时调节镜头广角/长焦。

## ⌨️ 快捷键说明 (Controls)

| 按键 | 功能 | 说明 |
| :--- | :--- | :--- |
| <kbd>F10</kbd> | **呼出 / 关闭菜单** | 打开角色选择与相机设置窗口 |
| <kbd>F11</kbd> | **切换人物目标** | POV 状态下按序循环附身下一个角色 |
| <kbd>F12</kbd> | **自由飞行开关** | 快速进入 / 退出自由飞行模式 |
| <kbd>R</kbd> | **重置视角朝向** | POV 状态下将视线重新对准角色面部正前方 |
| <kbd>鼠标右键</kbd> (按住) | **旋转镜头** | 自由环视（POV / 飞行通用） |
| <kbd>鼠标滚轮</kbd> | **调节 FOV** | 调整视野缩放（长焦特写 / 广角全景） |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> | **飞行平移** | 仅自由飞行模式有效 |
| <kbd>Q</kbd> / <kbd>E</kbd> | **飞行升降** | Q 下降，E 上升 |
| <kbd>Left Shift</kbd> (按住) | **飞行加速** | 自由飞行模式下 4 倍速移动 |
| <kbd>↑</kbd> <kbd>↓</kbd> + <kbd>Enter</kbd> | **菜单键盘导航** | 打开菜单后可完全使用纯键盘选人 |

> 💡 **提示**：所有快捷键均可在 `BepInEx/config/ntr.povcam.cfg` 中修改，亦支持通过 `BepInEx Configuration Manager` (F1 面板) 实时改键。

## 📥 安装方法

1. 确保游戏已安装 [BepInEx 5.x (Unity Mono)](https://github.com/BepInEx/BepInEx/releases)。
2. 下载本项目 Release 中的 `NTRPovCam.dll`。
3. 将 `NTRPovCam.dll` 放入游戏的 `BepInEx/plugins/` 目录下。
4. 启动游戏即可生效。

## ⚙️ 常见问题 (FAQ)

#### Q: 开启主角第一人称后，为什么镜头还是看到后脑勺？
- 请检查 `F10` 菜单中的 **“第一人称时隐藏该人物头部”** 选项是否勾选（默认开启）。
- 本插件 v2.4+ 采用了后动画骨骼缩放机制，确保在动画计算后自动隐藏面部与头发网格。

#### Q: 某些场景里主角显示“未激活”？
- 这是游戏本体的运行机制（部分剧情或常态下主控模型会被 SetActive 关闭）。
- 插件内已做兜底兼容，即便标记为 `(隐藏)` 的角色，在菜单中选择后也会强制唤醒其模型动画并成功附身。

#### Q: 退出视角后相机没有还原？
- 按 `F10` 点击菜单中的 **“关闭 POV”**，或重新按一次 `F12` 退出飞行。
- 如果被游戏剧情强制回收镜头，插件会自动检测并安全释放相机接管权。
